# 使用加密文本切片传递 ZIP

标准 ZIP 分卷缺少 Python 标准库的跨平台读写支持。本项目先生成单个 ZIP，再按 50,000,000 字节的 TXT 上限切片；每片使用同一密码经 scrypt 派生的密钥和独立 AES-GCM nonce 加密，连同版本、随机盐、归档标识、序号及总数一起进行认证，最后编码为 Base64。还原必须用本脚本按序解密并拼接，单个分片不是标准 ZIP 分卷。这种格式避免依赖各平台不同的压缩命令，但将来改变格式时必须保留旧版本的读取能力。

## 2026-09-30 补充

TXT 上限改为压缩时可选的 1～200 MB，默认仍为 50 MB。格式头不变；还原程序按单片实际大小读取并校验，统一限制在 200 MB 内，因此使用者无需记住压缩时选的数值。旧版归档仍可还原；超过 50 MB 的新分片须使用新版程序。
