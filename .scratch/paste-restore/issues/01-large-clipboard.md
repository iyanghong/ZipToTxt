# 多个大文本的粘贴还原与响应验证

Status: ready-for-human

新增侧栏“粘贴文本还原”，输入项可增删及替换，支持按钮和粘贴快捷键。界面只显示摘要；完整文本经后台读取、去空白、校验及暂存，不进入偏好文件。按内部片号排序，并检查缺片、重复及归档混杂。

验收使用三份分别超过 100 MB 的真实加密文本，通过系统剪贴板乱序粘贴；确认结果 SHA-256 与原文件一致。记录粘贴、错误密码重试及解密解压时 20 ms 定时回调的实际最大延迟，本测试环境以 250 ms 为上限。记录 GUI 常驻内存变化，确认多片输入未导致全文在 GUI 进程中累积。数据及剪贴板提供者使用外部进程，测量排除测试数据生成期间。

覆盖非法字符、空白和单个末尾 NUL、截断、超限、重复、混入归档、输入替换失败后的保留及重试、已有输出保护，以及成功／关闭清理。验证打包后实际可执行文件启动工作进程，不能仅以源码后台线程或假剪贴板作为验证依据。
