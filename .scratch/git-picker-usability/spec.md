# Git 提交选择与文件预览优化

Status: ready-for-human

讨论日期：2026-10-07。用户确认推荐方案，源码、文档、测试和三个平台本地打包已完成。

## 用户提出的需求

1. 分支允许关键字过滤。
2. 提交日期支持快捷选择，例如当天；日期输入框弹出日期选择，也允许手动输入。
3. 提交列表提供多选按钮。
4. 选择后能够预览最终涉及哪些文件及其数量。

## 已核对的现状

分支为只读下拉框，没有搜索。起止日期为普通输入框，点击应用筛选才查询。提交表格支持键盘组合多选和清空选择，每次累计显示 200 条；查询已取得全部筛选结果。

日期和作者筛选保留列表外的已选提交，实际更换分支清空选择。确认提交后，主界面只保存提交标识；重新打开选择窗口不会回填之前的选择。

文件预览目前在主界面开始压缩时触发，须先填写密码。现有预览显示去重后的可打包路径、缺失路径及数量，没有文件大小或搜索功能。确认预览直接开始加密。

## 继续采用的归档规则

只包含所选目录及其子目录；所选提交决定去重路径，实际内容取打包时当前磁盘版本。缺失路径跳过，全部缺失时不生成空包。系统没有 Git 时，普通压缩和还原仍可使用。

日期继续按提交时间、本机时区、起止日期包含全天解释。分支查询只使用本机已有历史。异步查询和打包保持界面响应。

## 已确认的交互

### 分支关键字

独立搜索框，按分支名不区分大小写包含匹配，覆盖本地及远程跟踪分支。关键字只影响候选列表；明确选择另一分支才更换提交范围并清空选择。

### 日期选择

快捷项为当天、昨天、最近 7 天、本月、不限；最近 7 天包含今天，本月包含月初至月末。快捷项直接应用查询；起止日期框支持弹出日历及手动输入 YYYY-MM-DD。

### 多选按钮

逐行勾选框、全选筛选结果、反选筛选结果、清空全部。全选及反选覆盖全部筛选结果，包括尚未加载的行；不影响其他筛选范围内已保留的选择。清空全部清除所有选择。

### 文件预览时机

确认提交后立即生成打包文件清单，无需先填密码；展示去重路径、可打包数量、未压缩总大小和缺失文件。支持返回修改提交；确认清单后回主界面设置密码，开始压缩时重新核对文件。

## 实施约定

采用只读文件表格展示路径、大小和可打包／缺失状态。返回修改提交保留当前筛选和勾选，重新打开提交窗口回填上次确认的选择。没有可打包文件时仍展示缺失清单，确认按钮禁用。主界面开始压缩时重新读取当前文件并展示最终清单，沿用已有确认和打包流程。

日期控件使用 Tkinter 和标准库 calendar，沿用系统控件与现有打包依赖。完成后覆盖真实控件、日期边界、超过 200 条历史的批量选择和加密还原测试，重新构建三个平台本地产物。

四项交互已实现。真实控件测试覆盖分支过滤、日期输入及快捷项、205 条历史的批量选择、提前预览及返回、选择回填、全缺失阻止空包，以及加密还原。额外的键盘检查发现并修正了日历抢走输入框焦点的问题；最终三平台包内代码均验证了日历打开时的手动输入。
